RAIV Fleet dashboards

Two independent live views of the same truck, one per data source. They are deliberately separate: each page opens its own broker connection and subscribes to only its own topics, so neither can show the other's numbers.

StrideLinx feed

The router polling the CLICK PLC over Modbus TCP. 45 tags, roughly one update per minute. Has a pause control.

CM5 HMI MQTT feed

Why two pages instead of one

The two sources overlap on only 11 tags — StrideLinx carries 34 the CM5 doesn't, the CM5 carries 28 StrideLinx doesn't. Keeping them apart means a number on screen has exactly one provenance, and the 11 shared tags can be compared side by side as a correctness check between two independent paths to the same PLC.

On pausing: the pause control on the StrideLinx page stops that page's broker subscription. It does not stop the router polling the PLC — the dashboards sit downstream of the broker and are not in the Modbus path. Taking the router's polling off the machine network is done in StrideLinx Fleet Manager.

Read-only, subscribe-only broker credential — neither page can write to a PLC or the HMI. History lives in logs/.
