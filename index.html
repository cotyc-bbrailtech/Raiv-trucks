Why the sources are kept apart

The truck and the bench run near-identical programs, so their tags share names and topic suffixes — both use g1, g18 and so on. On 2026-08-07 the bench was found publishing into raiv-tracker/truck-2/* and being recorded as truck data. It now has its own raiv-tracker/lab/* prefix, and each page validates the full topic rather than just the gN suffix, so a stray message from the wrong machine is ignored instead of overwriting a value.

On pausing: the pause control stops that page's broker subscription. It does not stop the router polling the PLC — these pages sit downstream of the broker and are not in the Modbus path. Polling is controlled in StrideLinx Fleet Manager.

Read-only, subscribe-only broker credential — no page can write to a PLC or an HMI. History lives in logs/.
