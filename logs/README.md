# Raiv-Tracker MQTT logs

Auto-generated by `.github/workflows/mqtt-excel-logger.yml`, which runs every
10 minutes, listens to the Raiv-Tracker HiveMQ broker for ~90 seconds, and
commits any new readings here.

One file per calendar day, never overwritten:

```
raiv_tracker_2026-08-06.xlsx
raiv_tracker_2026-08-07.xlsx
...
```

Each file has a single `Log` sheet with columns `Timestamp | Truck | Tag |
Value | Datatype | Topic` -- one row per tag reading. See
`scripts/mqtt_excel_logger_action.py` for exactly how rows are produced, and
the top-level project docs for the coverage trade-off of this schedule-based
approach (roughly one reading per tag per 10-minute run, not full
minute-by-minute history).
