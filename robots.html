Reading the cycle figures

The cycle numbers are not all measured the same way. Some come from the controller's own cycle log (cycles_ALL.csv), and 2RT57's latest figures come from OCR of Apera Vue logs. The windows and the programs differ too, so compare robots with care. Each card names its source file.

Robot code (.pgx, .dtx, .cfx) and backups are listed in each robot's manifest.csv with their OneDrive location but are not copied here: the connector used to pull this data returns them as binary.
