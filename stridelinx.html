Connecting…

What pausing does: it disconnects this page from the MQTT broker, so the values below stop updating and this browser stops consuming broker traffic. It does not stop the StrideLinx router polling the PLC over Modbus. This page sits downstream of the broker and is not in the Modbus path at all — to actually take the router's polling off the machine network you have to disable the data source (or its tags) in StrideLinx Fleet Manager. See the project doc for the exact steps.
